# Udemy Clone

A responsive Udemy website clone built using HTML and CSS. This project replicates the basic layout and design of the Udemy homepage, helping me practice frontend web development concepts such as Flexbox, positioning, animations, and responsive design.

## Technologies Used

* HTML5
* CSS3
* Font Awesome
* Google Fonts

## Features

* Responsive Navigation Bar
* Search Bar UI
* Course Categories Section
* Hero Banner Section
* Smooth Hover Effects
* Animated Udemy Logo
* Modern and Clean User Interface
* Responsive Layout
